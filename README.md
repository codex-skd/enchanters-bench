# Enchanter's Bench

A NeoForge 1.21.1 port of **Enchanting Plus**: an advanced enchanting table that lets you choose exactly which
enchantments, and at what level, go on your item, instead of rolling for them.

> **Status: in development.** See `docs/PLAN_PORT.md` (Spanish, internal).

## Attribution

Enchanter's Bench is a port of [Enchanting Plus](https://www.curseforge.com/minecraft/mc-mods/enchanting-plus)
(LGPL-3.0), originally created by **lclc98**, **Xkyouchoux**, **odininon** and **GnRSlash**, maintained by
**Darkhax**, with contributions from Jaredlll08, Shadows-of-Fire and translators. This port is unofficial and is not
affiliated with or endorsed by the original authors. See `NOTICE`.

## Differences from the original

NeoForge 1.21.1 instead of Forge 1.12.2; data-driven enchantments; JSON recipes; NeoForge config and networking APIs;
no Bookshelf dependency; JEI and CraftTweaker integrations not included; own mod id `enchanters_bench` (variant
`eplus` renamed `bench`). Vanilla textures are not redistributed.
